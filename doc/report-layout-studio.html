Last layout used per report type

GET /api/ReportLayout/last-used/{reportType}

How a report picks its layout

  1. 1
    Explicit layoutIdThe export call names a layout. It must be active and belong to this company (or be a system layout), otherwise the export fails.
  2. 2
    Last used for this report typeEvery successful export stores the layout against the report type, so the next export of the same report reuses it.
  3. 3
    Company defaultThe active company layout flagged isDefault, then any active company layout by name.
  4. 4
    System defaultThe seeded SYSTEM_DEFAULT layout. The export fails only when nothing at all is available.
Marking a layout as default clears the flag on every other layout of this company. Deactivating a layout also clears its default flag.
